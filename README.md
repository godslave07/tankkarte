# TankKarte — PWA с картой цен на топливо

Статическое веб-приложение: без сборки и без зависимостей, кроме Leaflet с CDN.

## Запуск
Из папки `arb`:
```
python -m http.server 8766 --directory TankPreise/pwa
```
Затем откройте http://localhost:8766. Service worker и геолокация работают только на `localhost` или по HTTPS.
Чтобы установить приложение на телефон, его нужно выложить на любой HTTPS-хостинг (GitHub Pages, Netlify, Cloudflare Pages).

## Файлы
- `index.html` — разметка: карта, верхняя панель, нижняя панель, карточка, настройки.
- `app.js` — вся логика: API Tankerkönig v4, Nominatim, геолокация, маркеры, список, кэш, автообновление.
- `style.css` — тёмная тема, мобильная вёрстка (≥ 900 px — панель слева).
- `sw.js` — офлайн: оболочка приложения, Leaflet, просмотренные тайлы карты.
- `manifest.webmanifest`, `icon.svg` — установка как приложение.

## Данные
- Цены: `https://creativecommons.tankerkoenig.de/api/v4/stations/search` (MTS-K, CC BY 4.0).
  В отличие от `list.php`, v4 отдаёт время последнего изменения цены по каждому виду топлива.
- Геокодинг: OpenStreetMap Nominatim, только по запросу (без автодополнения — так требуют правила Nominatim).
- Последний ответ хранится в `localStorage` (`tk.last`) и показывается сразу при запуске и без сети.

## Ограничения запросов
- Автообновление — не чаще раза в 5 минут, только когда вкладка видна.
- Повторное нажатие «Обновить» в течение 20 с не отправляет запрос.
- Уменьшение радиуса и смена топлива или сортировки не делают запросов, всё пересчитывается локально.
